# 版本 v4.1 - 2026-03-18

## 新增

* 新增 **MySQL 与 MongoDB 连接测试功能**。在启动脚本执行时会自动检测数据库连接状态，如果连接测试未通过，则系统启动流程会终止并提示错误信息，以避免因数据库不可用导致系统异常运行。
* 新增 **司南管理端启动校验机制**。在管理端服务启动时会自动检测数据库连接状态，确保系统依赖的数据库服务处于正常可用状态。

## 优化

* 优化 **日志输出路径结构**，统一日志存储位置，方便用户快速定位问题并进行反馈。
  当前所有系统日志统一存储在部署目录下的：

  PilotOS-Log

  目录中，用户可在该目录中查看系统运行日志及相关错误信息。

## 修复

* 修复 **司南管理端主页面相关文档无法获取的问题**，确保管理端页面可以正常加载和访问相关文档资源。

## 变更

* 修改 **V20 芯片拓扑结构**，调整为 **20 个量子比特全连通拓扑结构**，以更准确地反映当前硬件架构能力。
# 版本 v4.2 - 2026-04-29
## 优化
* 优化系统管理页面，提供中英文支持；
* 优化变分计算服务，支持多线程并行安全访问；
* 完善激活码验证功能的回复消息，补充错误码字段；
* 优化司南映射算法，引入swap门回退机制，确保映射成功；
* 优化变分计算服务，支持对变分线路结构进行映射。
